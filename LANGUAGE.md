# Language support / Dil desteği

The add-on uses XenForo's native phrase system for user-visible text. New user-visible strings should be added as phrases instead of being hard-coded in templates, PHP or JavaScript.

Eklenti, kullanıcıya görünen metinler için XenForo'nun native phrase sistemini kullanır. Yeni kullanıcı metinleri template, PHP veya JavaScript içine sabit yazılmak yerine phrase olarak eklenmelidir.
